# Nexora — экономика студенческого стартапа

Страница для защиты проекта команды Nexora, ЧГУ. Иса Дадашев — руководитель проекта; Мальсагов Ахмед — креативный директор. Стадия — разработка MVP. Сайт не заявляет полученный грант, проведённые пилоты или существующих платящих клиентов.

## Локальный запуск

Node.js 22+ и npm или pnpm:

```sh
npm install
npm run dev
```

```sh
npm test
npm run build
npm run preview
```

В рабочей среде Codex зависимости повторно используются из предыдущего проекта через локальную ссылку `node_modules`. Она игнорируется Git; при переносе выполните `npm install` или `pnpm install`. Код не зависит от абсолютных путей. Старый сайт не изменён. Сборка находится в `dist`.

## Возможности

- Фиксированный грант 1 000 000 ₽ и шесть независимо редактируемых статей. Остаток и превышение видны сразу; автоперераспределения нет. Результаты и критерии приёмки раскрываются в статьях.
- План на 12 месяцев и способы проверки пяти бизнес-гипотез.
- Калькулятор месячной работы после пилотов. Три ползунка и раскрываемые допущения. Переключатели 10/20/40 — иллюстрации, не прогноз.
- Локальное сохранение параметров, обработка недоступного хранилища, сброс с возможностью отмены.
- Режим «Для жюри»: крупный текст, скрытые подробные поля редактирования; ползунки остаются для живой демонстрации. Escape завершает показ.
- «Печать» на ноутбуке или команда печати браузера формирует краткую версию с текущими цифрами. На телефоне используйте меню браузера.
- Нет внешних шрифтов, аналитики, сервера, отправки данных или публикации.

## Модель

Единый источник параметров и расчётов — `src/model.ts`. Ставки комиссии и резерва задаются в процентах, в формуле делятся на 100.

Выручка = подписки × цена.
Расходы = подписки × переменные расходы + выручка × (комиссия + резерв) / 100 + постоянные расходы.
Результат = выручка − расходы.
Вклад подписки = цена × (1 − комиссия / 100 − резерв / 100) − переменные расходы.
Порог = округление вверх(постоянные расходы / вклад), только при положительном вкладе.

База: 10 подписок, цена 15 000 ₽, переменные 3 000 ₽, постоянные 60 000 ₽, комиссия 2%, условный резерв 6%. Выручка 150 000 ₽, результат 48 000 ₽, порог 6 подписок. При 20 подписках результат 156 000 ₽.

Бюджет разработки и коммерческий месяц — разные периоды. Срок окупаемости гранта не вычисляется. Налоговый резерв — допущение модели, не налоговая консультация. Смету необходимо сверить с правилами конкретного конкурса.

## Проверки

Девять автоматических тестов: контрольные числа, граница безубыточности, ноль подписок, неположительный вклад, ноль постоянных расходов, редактирование бюджета и восстановление хранилища. TypeScript strict и production-сборка.

В браузере: 1440×900 и 390×844, нет горизонтального переполнения; раскрытие статей, изменение сумм, остаток и превышение; 20 подписок и пересчёт; клавиши стрелок/Home/End; сохранение после перезагрузки; сброс; скрытие полей в режиме жюри и выход по Escape. Подробности проверки — `QA.md`.
