# Nexora: дизайн страницы защиты

Основа: существующая архитектура React + TypeScript + Vite из соседнего проекта. В новой рабочей папке исходников и AGENTS.md не было. Старый проект не изменяется.

Палитра: фон #f7f6fb, бумага #ffffff, текст #242135, основной фиолетовый #6d43d4, мягкий сиреневый #eee8fa, оранжевый #d66b2f. Основной шрифт — системный с кириллицей (Segoe UI / Arial); крупные заголовки, спокойный основной текст. Числа табличные.

Композиция: шапка → обещание продукта и пример поручения → распределение гранта (круг и раскрываемая ведомость результатов) → четыре этапа → калькулятор → проверка гипотез → команда. Выравнивание по левому краю. Редактирование и детали вторичны, суммы и результаты видны сразу.

Проверка замысла: вместо набора одинаковых карточек используются крупная типографика, один наглядный круг бюджета, список статей, линия этапов и контрастная панель результата. Оранжевый выделяет действия и последовательность. Иллюстрация работы продукта подписана как пример, а не готовый интерфейс или достижение.

Источники инструкций: anthropics/skills frontend-design и vercel-labs/agent-skills web-design-guidelines (прочитаны 19.10.2026).
